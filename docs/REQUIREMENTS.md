# REQUIREMENTS

## 目的
中学生・保護者が「目黒高校を知る → 雰囲気を感じる → 行ってみたい → 正式申込へ進む」と自然に移行できる学校説明会特設サイトを作る。

## 必須体験
- 10月説明会を主役にする。11月・12月は参考情報。
- 生徒による校内案内と応援パフォーマンスを主要訴求にする。
- 初期画面で学校名、10月説明会、確定日または未定、申込状態を把握できる。
- 回遊する利用者と、すぐ申込情報を見たい利用者の両方に対応する。
- スマートフォンを最優先する。

## 情報の正確性
- 日時、場所、対象、定員、申込URL、実施内容を推測しない。
- 未確認項目はnullで保持し、安全な未定表示にする。
- 申込URL・日付・状態はHTMLへ重複直書きしない。
- 受付状態は `unknown / scheduled / open / full / closed / ended / postponed / cancelled` の8状態。
- `open` は正確な日付、開始時刻、会場、対象、HTTPS申込URL、確認時刻が揃わなければビルド失敗。
- 自動的に受付開始へ切り替えない。締切後・終了後は安全側へ変更可能。

## 写真
- 実際の学校・生徒写真のみ使用する。
- AI生成の架空の目黒高校・生徒を実写代替として掲載しない。
- 公開可否、alt、焦点位置、寸法をphotos.jsonで管理する。
- プレビューでは写真準備中を表示可能。本番では欠落写真枠を消せる。

## デザイン
- 白・オフホワイト中心、Navy本文、深緑は仮アクセント。
- GlassはHero案内面・短いキャプション・固定CTA外側など限定使用。
- 全画面Glass、浮遊球体、液体ガラス、虹反射、無意味な3Dは禁止。
- 写真を主役にし、カードの反復でLPを均質化しない。
- PCでは12列、スマホでは4列を基準にする。

## アクセシビリティ
- h1は1つ、semantic HTML、skip link、main/nav/section/dl/time相当を使用。
- 本文16px以上、主要CTA48px以上、その他操作44px以上。
- 200%拡大、320 CSS px、キーボード操作を想定。
- prefers-reduced-motionとサイト内「動きを減らす」に対応。
- JSが失敗しても本文・情報・リンクが読める。

## 技術
- 静的HTML + CSS + 小さなVanilla JS。
- Node事前生成。
- React / Three.js / GSAP / CMS / DB / 認証 / PWAは初版では導入しない。
- Cloudflare Workers Static Assetsで配信可能なdistを生成する。
